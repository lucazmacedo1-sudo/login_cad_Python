🔐 Sistema de Login em Python

Meu primeiro projeto em Python com interface gráfica e banco de dados.

    📌 Sobre o projeto

Este projeto é um sistema de login desenvolvido em Python.
Ele permite que usuários façam cadastro e login, salvando os dados em um banco de dados MySQL.

Criei este projeto para praticar programação, banco de dados e interface gráfica.

🚀 Tecnologias utilizadas

- Python
- CustomTkinter
- MySQL
- SQL

⚙️ Funcionalidades

- Cadastro de usuário
- Login com verificação
- Integração com banco de dados
- Interface gráfica

🧠 O que eu aprendi

- Conectar Python com MySQL
- Criar interfaces gráficas
- Trabalhar com funções e eventos
- Organização básica de projetos

▶️ Como executar

1. Instale o Python
2. Instale as dependências:
   pip install customtkinter mysql-connector-python
3. Execute o arquivo principal:
   python main.py
